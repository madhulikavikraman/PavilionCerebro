Building health, structural safety, predictive maintenance

One AI swarm that watches every system in your building and tells your facilities team what to fix first.

Pavilion Cerebro is for owners and facility managers of commercial buildings. Specialist agents watch cracks, concrete, building telemetry, battery storage and chillers. One coordinator fuses their findings into a single ranked picture and acts before small problems become expensive failures.

How it works: one platform, not a pile of point tools

Every agent implements the same interface: ingest its data, output a calibrated 0-1 risk score with evidence, report to the coordinator. Adding a subsystem means writing one more agent, not rebuilding anything.

What's real, what's simulated, what's next

We say exactly where the line is. That is the credibility of the prototype.

Real

  • Crack detection: the team's existing inspection cascade (local/Claude vision models), wrapped as Agent 0, plus an offline OpenCV fallback measured on 1,600 held-out images
  • UPV material data: University of Minnesota DRUM UHPC dataset (CC0)
  • BMS telemetry: CU-BEMS, a real office-building management system (CC BY 4.0)
  • Battery aging: NASA Ames PCoE Li-ion dataset
  • Chiller faults: ASHRAE RP-1043 (CC0)
  • All detection, fusion and prioritization logic

Simulated

  • The building: datasets from different sources are mapped onto one fictional building
  • Mitigation actions: log entries and dashboard state, no real building control
  • Timeline: datasets are replayed on a shared clock

Roadmap

  • Plumbing and water-damage agent: no public dataset exists, needs a field-data partnership
  • Fire and smoke visual agent: public image datasets exist, next sprint
  • Real control integration (BACnet / BMS vendor APIs)

Run the live dashboard

The working prototype runs locally: the Python agents, coordinator and dashboard. This site only presents it and does not run the pipeline.

pip install -r requirements-cerebro.txt
python -m dashboard.server        # http://localhost:8765
